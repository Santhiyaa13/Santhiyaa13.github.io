# Santhiya K — Portfolio

A fast, dependency-free portfolio site (HTML + CSS + vanilla JS).

## Publish on GitHub Pages (about 5 minutes)

1. On GitHub, create a **public** repository named `Santhiyaa13.github.io` (exactly your username + `.github.io`).
2. Upload everything in this folder (`index.html`, `style.css`, `script.js`, the `assets/` folder, `README.md`).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute your site is live at `https://santhiyaa13.github.io`.

## Fill in your own details

Open `script.js` and edit the `LINKS` block at the top: add your LinkedIn, LeetCode and project repo URLs.
Any link you leave empty is hidden automatically, so nothing looks broken.

## Add dashboard screenshots

Put PNG screenshots in `assets/` named `dashboard-1.png` to `dashboard-4.png` (and edit captions in `index.html`).
The "Dashboards" section appears automatically only when images exist.

## Add or update your resume

1. Rename your resume file to exactly `Santhiya_K_Resume.pdf`.
2. In your GitHub repository, open the `assets` folder.
3. Click **Add file → Upload files**, drag your PDF in, and click **Commit changes**.
   If a file with that name already exists, GitHub replaces it.
4. Wait about a minute, then refresh your site. The Resume buttons now download your file.
